# recipebook requirements
- Version 1.0
## Functional
1. Uses local database
2. Databases can be exported and imported
3. GUI should be simple web app with support for mobile users
- User should be able to add, remove and edit recipes
- There should be filter and search functions
4. Function to create weekly or monthly rotating recipe calendar
5. Main idea is that user writes recipe name and can add link, text file or image with recipe in it
- User should be able to tag recipes like 'Vegetarian', 'Chicken', 'Beef' and other meaningful tags
## System and hardware
1. Must be docker deployable
